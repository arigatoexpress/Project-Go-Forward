# Staff guides

These guides are for the Texas Home Outlet team. You do not need any tech skills to use them.

The website is https://www.texashomeoutlet.com

The staff sign-in page is https://www.texashomeoutlet.com/staff

Bookmark the staff page on your phone and on the office computer.

## Guides you can use today

| Guide | What it helps you do |
|---|---|
| [How to sign in](staff-sign-in.md) | Get into the staff side of the website with an email link or a 6-digit code. Start here. |
| [How to add photos to a home](photo-upload-guide.md) | Put pictures on a home so customers see them on the Inventory page. |
| [Passkeys (optional)](passkey-setup-guide.md) | Background on passkeys. You do not need one. The sign-in page uses email. |
| [Turn on email sign-in (owner only)](owner-setup-email-sign-in.md) | One-time setup steps for the owner. Most staff can skip this. |

## Quick safety rules

- Never text or email your sign-in code or the backup PIN to anyone.
- Never type a customer's Social Security number or bank account number into the chat.
- On a shared computer, tap **Sign out** when you are done.
